УСТАНОВКА PWA НА ANDROID

Важное: PWA устанавливается из браузера только с HTTPS-хостинга (или localhost).
Самый лёгкий способ — бесплатно загрузить файлы в GitHub Pages.

1. Создай GitHub аккаунт (если нет).
2. Создай новый репозиторий, например image-compare-pwa.
3. Загрузи ВСЕ файлы и папку icons из этого архива в репозиторий.
4. В Settings → Pages выбери Deploy from a branch, Branch main, Folder /root, Save.
5. Подожди, пока GitHub Pages выдаст ссылку вида https://USERNAME.github.io/REPO/.
6. Открой ссылку в Chrome Android.
7. Меню ⋮ → «Установить приложение» / «Добавить на главный экран».

Приложение кешируется и после первого открытия может работать офлайн.
Для обновления: заменить файлы в GitHub; при следующем открытии обновится версия.

Не открывай index.html напрямую из файлового менеджера: для установки PWA нужен HTTPS.
